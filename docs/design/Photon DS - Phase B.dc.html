Specs

Semantics

All checkIncome Expenses Crypto ← filter · selected = Subtle fill + check
rio-trip.pdf close Beta Pending ← input w/ remove (48dp hit) · status tags
Rules
  • Height 32 · Radius.Full · padding X 12 · label 13/600 · icon Sm 16, gap 6. One size (chips don't scale with SizeVariant).
  • Kinds: Filter (toggle; selected = Primary-subtle fill + Primary border + check), Input (removable; close 20dp visual, 48dp hit), Tag (non-interactive status, Subtle pairs).
  • Chip rows: Row(wrap) gap 8, or horizontal ScrollView with 16dp gutter for single-line filter bars.

mouseDesktop & pointer — contract per §10
Pointer

Keys
A chip is a tab stop; Space/Enter toggles or activates; Delete/Backspace removes a removable chip — the ✕ is not a separate stop.
Semantics
Filter/toggle chip = button + aria-pressed (or option inside a listbox group). Remove mirrors as a custom action on native — REQUEST (§10).

Rules
  • Track 52×32 Radius.Full — off: BorderStrong fill · on: Primary. Thumb 26dp white, E1 shadow, 3dp inset. Hit rect 48, extends over the paired label row in ListItems.
  • Toggle: thumb slides Base 200ms standard + track crossfades. Draggable: thumb follows the finger, release settles by position + velocity (Release glide — 200ms smoothstep (§06); velocity spring still REQUEST); press-down stretches the thumb to 30dp wide (rrect, engine-honest).

Keys
Tab stop · Space toggles · ←/→ set off/on explicitly.
Semantics
role=switch + aria-checked — never "Notifications on" as a name (§10). Native Checked field: REQUEST.

Rules
  • 8 rrect bars (2×5 at 16dp), opacity phase-staggered, 800ms/rev linear — no arcs exist in the engine; this is the canonical activity indicator on both platforms.

Skeleton

new Skeleton(shape: SkeletonShape.Line | Circle | Block, width, height)
Rules
  • Shapes: Line (12dp, Radius.Full, widths 100/70/45%), Circle (avatar sizes), Block (Radius.Md) — SurfaceSubtle base + a translating 2-stop gradient tint (one clipped layer; engine-honest, no mask).
  • Mirror the real layout's dimensions — content must replace skeleton with zero shift. Skeleton the first ~1.5 viewports only.
  • All shapes share one 1.4s phase (single global clock — no sparkle chaos). Real content crossfades in 200ms as it arrives, per region.
  • Show only for loads expected > 300ms; Reduce Motion → static SurfaceSubtle, no sweep.
  • A11y: shapes hidden; the region announces "loading content" once, then "loaded".
  • Skeleton = structural loads. Action feedback = Button loading / Spinner. Never skeleton a whole screen behind a Modal.
mouseDesktop & pointer — contract per §10
Pointer
Inert; no hover interplay with the shimmer.
Semantics
Hidden; the loading region announces busy once, then announces the content when it lands.

Banner / Alert

new Banner(status: Variant.Warning, title, body?, actions: [...]?, dismissible: true)
info
Scheduled maintenance — transfers may be slower on Sunday 02:00–04:00.
check_circle
Identity verified. All account limits are now unlocked.
warning
Your card expires this month. Renew it to keep automatic payments running.
Renew card Remind me later
close
error
Payment failed. Your balance was not charged — try another method.
Rules
  • Inline surface (scrolls with content, top of the region it describes): Radius.Lg 14 · Subtle pair fill per status · padding 12/14 · icon Dense 20 + gap 10 · text 13, bold lead-in instead of a separate title row.
  • Actions: ≤ 2 text buttons in OnSubtle (primary 700, secondary 600 @ 75%), hit 48. Dismiss X only for non-critical banners (glyph 18, hit 48).
  • Enter: fade + height Slow 300ms decelerate (layout animates once — allowed exception); exit ⅔ accelerate.
  • A11y: Warning/Destructive = assertive alert role; Info/Success = polite status. Dismiss = custom action.
  • Banner is persistent context — transient confirmations are Toast (Phase C); blocking decisions are Modal (Phase C). Max 1 banner per screen; never stack.
mouseDesktop & pointer — contract per §10
Pointer
Static surface; its actions hover per Button. Never dismissed by hover or timer — a Banner is persistent state.
Keys
Actions are ordinary tab stops; a dismissible Banner’s ✕ is the last stop inside it.
Semantics
role=status (polite) for info/success · role=alert for error severity. Content change re-announces.
