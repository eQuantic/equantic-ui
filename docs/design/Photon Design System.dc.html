Photon Mobile
Design System

The component specification for eQuantic.UI — one write-once component library (eQuantic.UI.Components, 44 components authored in C# against eQuantic.UI.Primitives), realized per target: DOM/CSS on web, the Photon GPU renderer on native. Every visual in this document is drawn inside the v1 engine fence: rounded rects, uniform borders, 2-stop linear gradients, rrect shadows, glyph-atlas icons and shaped text — nothing else.

layers Structured as three layers — a shared token core, two realizers, one write-once component library — so both targets run the same classes and the same foundations instead of re-deriving them. See the architecture ↓
