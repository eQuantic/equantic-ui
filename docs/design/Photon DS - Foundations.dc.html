Foundations · §00–§10

Architecture, the engine fence, tokens (color · type · spacing · radius · elevation · motion · iconography · touch), the C# token API, and the §10 interaction contract — states, pointer behavior and semantics — that every component spec inherits.

◆

Architecture — three layers

one token core · one write-once library · two realizers

Photon is not a standalone system — it is the native realizer of eQuantic.UI. There is one component library, written once; the layers split what is authored once from what each realizer owns. Read the stack bottom-up: the library is authored against the shared core; each realizer turns the same built tree into its runtime — DOM or GPU display list.

Layer 3 · Components — one write-once library authored once in C# · literally the same class on every target
eQuantic.UI.Components — 44 shipped components, authored once against the abstract vocabulary in eQuantic.UI.Primitives (Box · Row/Column · Grid · Stack · ScrollView · Overlay · Anchored · Pressable · Text · TextEntry · Icon · Image …). Not two similar APIs — the same C# class reaches both targets. This doc's Phase A/B/C specs are its contract; anatomy adapts per target from the same class (Select & DatePicker: BottomSheet on touch, anchored popover on pointer).
Web-specific behavior — hover, focus-visible, cursor, right-click — is a realizer concern (§10), not a separate component library. The old two-library world (a ~77-component shadcn-like web lib with CVA class variants) is retired; nothing composes over Layer 2 except this one catalog.

Governing rules
  • One token PR moves both platforms — never fork the Layer 1 core per platform; deltas (elevation richness, touch sizing) are declared as platform overrides, not copies.
  • Presentation divergence is expected and documented per realizer, not smoothed into a lowest-common-denominator widget. Same class, same role — target-shaped anatomy.
  • A shared value that stops working on web (a contrast pair, a curve) is a token bug fixed in Layer 1, not a component patch on one side.
  • Hover, cursor, right-click and every other pointer behavior are specified here — §10 plus each spec’s Desktop & pointer note — and implemented by the realizers. There is no separate web component library to document.
00L2 · Platform · Photon

Engine constraints — the v1 fence

Normative. A component spec that needs anything from the right column is a spec bug. The renderer draws exactly this:

check_circle Renderer v1 draws
  • Rounded rects — per-corner radii, SDF anti-aliased
  • Borders of uniform width (inside stroke)
  • Linear gradients, 2 stops
  • Images: contain / cover / stretch / 9-slice
  • Box shadows of rrects (offset, blur, spread, color)
  • Clips: rect / rrect · opacity groups
  • Gaussian blur — expensive; overlays & sheets only
  • 2D transforms: translate · scale · rotate
  • Shaped text (HarfBuzz) + color emoji, glyph atlas
  • Scroll containers with native fling physics
cancel Not in v1 — design around it
  • Arbitrary vector paths / inline SVG
  • Dashed or dotted strokes
  • Complex masks, exotic blend modes
  • Generalized backdrop-filter
  • Per-side border widths
  • Conic / multi-stop gradients
  • Charts, maps, rich-text editors (out of catalog)
Icons are never SVG paths at runtime — they are glyphs from a font atlas or pre-rasterized bitmap atlas (§07).

Rules
  • Components consume tokens only; raw hex in widget code fails review.
  • Base colors are fills for OnBase text — never use Base as text on Surface (except Link, audited above).
  • Subtle pairs are for tinted containers: banners, badges, chips, icon-button tonal.
  • Disabled is not a color pair: it is a 38% opacity group on the resolved style (§05 · one saveLayer, uniform across variants).
Engine mapping
  • Colors stored sRGB, blended in linear premultiplied (engine color model).
  • Pressed = fill swap on the same rrect — no state-layer compositing cost.
  • Scrim = full-screen alpha rect; blur behind sheets is optional garnish (D4 budget), never required for legibility.
  • Focus ring = second rrect border (outer radius = control radius + 4dp), not a shadow.
02L1 · Shared token

Typography

Hanken Grotesk, bundled · shaped by HarfBuzz, rasterized by FreeType

One bundled family: Hanken Grotesk (OFL — embeddable in the SDK; tall x-height for small mobile sizes; weights 400–800; tnum for data). Bundling one family (D6: FreeType everywhere) means identical pixels on iOS and Android — a golden-harness requirement. System fonts remain available for user content via font discovery, but components default to the bundled family. Glyphs are atlas-rasterized at discrete sizes; the scale below is the whitelist that keeps atlas pressure bounded.

Dynamic Type policy
  • Reading roles (Body, Label, Caption) scale fully with the OS factor, up to ×1.3 tested tier.
  • Display/Heading clamp at ×1.15, Title at ×1.25 — layout titles must not explode.
  • Containers grow with text: control heights are minimums, padding is fixed, text wraps before it truncates (per-component rules state exceptions).
  • Scaled sizes snap to the atlas whitelist (nearest 0.5px step) to bound glyph memory.
Engine notes
  • Runs shaped once, cached by (text, style, width) — reshape only on change.
  • Alpha-mask glyphs at discrete sizes (8–40dp whitelist); no subpixel AA in v1.
  • Color emoji via COLR strikes → color atlas page.
  • Ellipsis is a shaping-time truncation (…), not a shader trick; max-lines supported on all text.
  • Data/code contexts use tnum feature — no separate mono family bundled in v1.

Spacing

4dp base · gap-owned, margin-free layout

Photon has no margin property. Spacing is owned by parents — Gap between children, Padding inside containers. This keeps the layout pass simple (no margin collapsing) and specs unambiguous.

Spec format
ShadowSpec(OffsetY, Blur, Spread, Color) — shadow color is #0F1720 in light and pure black in dark, at explicit alpha pairs per level — 0.10/0.45 · 0.12/0.48 · 0.16/0.52 · 0.20/0.56 · 0.26/0.62. Shadows alone don't separate dark surfaces. Levels E1–E2 additionally require a 1dp Border in dark mode (the doc cards you're reading do this). E3+ keep shadow only — their offset reads clearly.

Motion

animate transform & opacity only — both are free on the GPU
Standard
cubic(0.2, 0, 0, 1) · Base 200ms
{{ dotStandard }}
On-screen moves: tab indicator, segmented thumb, reorder
Decelerate
cubic(0, 0, 0, 1) · Slow 300ms
{{ dotDecel }}
Entrances: sheets up, toasts in, page push
Release glide · interim
smoothstep · Base 200ms — sanctioned (§06)
{{ dotGlide }}
Gesture releases (sheet snap, swipe settle, drawer, pull-to-refresh) pick their target by position + velocity, then glide there over 200ms smoothstep — the shipped behavior. The velocity-taking spring stays the target (REQUEST).
Fast 100ms — pressed feedback, hover-like states Base 200ms — most state changes Slow 300ms — surface enter/exit Exit = ⅔ of enter, accelerate cubic(0.3, 0, 1, 1) Release glide — Base 200ms · smoothstep · gesture releases only Reduce Motion → crossfade 120ms replaces all movement
The Release glide is the sanctioned interim; the spring is still a request. Gesture releases (drag glide-back, dismiss, detent snap) glide to the target picked at release over 200ms = Motion.BaseMs with smoothstep interpolation — the engine’s shipped release behavior. It lives in the gesture system, deliberately not as a Curve constant: Curve is exactly (X1,Y1,X2,Y2) with three beziers — SpringSpec, Curve.Spring(…) and Motion.Settle do not exist; the velocity-taking spring remains the TARGET and would have to be added to the SDK first. Layout-affecting properties (size, padding) animate only where a component spec explicitly allows it; the default is instant re-layout + animated transform/opacity garnish.
07L2 · Platform · Photon

Iconography

glyphs through the text pipeline — never SVG paths
Strategy
  • Ship an icon font built from the Lucide set (outline, 2dp stroke, 24 grid) — glyphs ride the existing FreeType → alpha-atlas path. Zero new pipelines.
  • Rasterized per density bucket (@1x @2x @3x) at the four canonical sizes — no runtime scaling of glyph bitmaps beyond the whitelist.
  • Two-tone / filled states (e.g. active tab) = the font's filled variant glyph, not a layered path.
  • Product-specific art (logos, illustrations) = bitmap atlas via Image (9-slice capable), pre-rasterized per density at build time by the SDK.
  • This document previews icons with a stand-in ligature font (Material Symbols Rounded); metrics and usage rules are identical.

08L2 · Platform · Photon

Touch targets & safe areas

Hit-slop model
Small · 32
48×48 hit
Every interactive node exposes a hit rect ≥ 44pt iOS / 48dp Android (engine uses 48dp both — the stricter). Visual bounds may be smaller; the framework auto-expands hit-slop symmetrically and asserts in debug when overlapping hit rects fight.
  • Adjacent small controls (icon rows): hit rects split the gap midpoint, never overlap.
  • Row-level targets (ListItem) absorb their children unless a child is independently interactive (trailing Switch).
Safe-area insets
content
area
  • Insets come from the platform shell each frame (rotation-safe).
  • SafeArea pads; edge components (AppBar, BottomNav, Sheet) extend their background under the inset and pad content — no letterboxing.
  • Scroll content: bottom inset added to content padding, so the last row clears the home indicator.

C# token API

typed structs — allocation-free, AOT-safe, no CSS anywhere 
// eQuantic.UI.Primitives — Layer 1 token core, shared by native AND web.
// Mode-free: the theme never knows the active mode. Web emits light-dark(light, dark);
// native resolves at paint via token.Resolve(ThemeMode). Full source: Tokens.cs
public readonly record struct Color(byte R, byte G, byte B, byte A);   // byte alpha; FromRgb/FromRgba/WithOpacity
public readonly record struct ColorToken(Color Light, Color Dark);   // + one-arg ctor · Resolve(ThemeMode) · WithOpacity
public readonly record struct VariantColors(ColorToken Base, ColorToken OnBase, ColorToken Pressed, ColorToken Subtle, ColorToken OnSubtle);
public readonly record struct TypeStyle(float Size, float LineHeight, FontWeight Weight, float Tracking, float MaxScale);
public readonly record struct ShadowSpec(float OffsetY, float Blur, float Spread, ColorToken Color);
public readonly record struct MotionSpec(int DurationMs, Curve Curve);
public readonly record struct Curve(float X1, float Y1, float X2, float Y2);   // Standard · Decelerate · Accelerate — no springs
public readonly record struct TransitionSpec(StyleChannels Channels, float DurationMs = Motion.BaseMs, float DelayMs = 0);

public enum Variant : byte { Primary=0, Secondary=1, Destructive=2, Outline=3, Ghost=4,
                            Link=5, Success=6, Warning=7, Info=8, Tertiary=9 }   // Tertiary aliases Info
public enum SizeVariant { Small, Medium, Large, XLarge }             // not "Size" — collides with SizeValue
public enum ShapeScale  { None, ExtraSmall, Small, Medium, Large, ExtraLarge, Full }
public enum FontWeight  { Regular=400, Medium=500, SemiBold=600, Bold=700, ExtraBold=800 }

public static class Space  { const float S1=4, S2=8, S3=12, S4=16, S5=20, S6=24, S8=32, S10=40, S12=48, S16=64, Gutter=S4; }

//   ExitFor(int) = enterMs * 2 / 3 · ReducedCrossfadeMs = 120 · no Settle, no springs.

public interface IAppTheme
{
    ColorToken Background { get; }  ColorToken Surface { get; }  ColorToken SurfaceSubtle { get; }
    ColorToken SurfaceHighlight { get; }  // translucent white — the Skeleton shimmer glint
    ColorToken Border { get; }  ColorToken BorderStrong { get; }
    ColorToken TextPrimary { get; }  ColorToken TextSecondary { get; }  ColorToken TextMuted { get; }  ColorToken TextInverse { get; }

// Usage — styles are structs; the reconciler diffs them by value:

10L2 · Both realizers

States, pointer & semantics

the interaction contract every component spec inherits — added by the v1.1 SDK audit

Normative for both realizers. The web realizer implements this section as :hover / :focus-visible atomic rules, ARIA attributes and focus management; Photon implements it through the pointer pipeline, the focus walk and the semantics tree. Each component spec carries a compact Desktop & pointer note that applies these rules; conflicts resolve in favor of this section.

The state system — now nine
default hover · pointer-only pressed focused disabled 38% loading error selected
  • Hover never fires on touch. A tap goes default → pressed with no hover in between; hover exists only for pointer: fine input.
  • Hover must clear when the pointer leaves the window — window-leave counts as pointer-out; no stuck hovers after alt-tab.
  • Hover in/out animates Motion.Press (100ms) — the same rung as pressed feedback.
  • Precedence: disabled mutes everything · pressed beats hover · the focus ring coexists with any fill.
  • Hover is garnish, never information — nothing may exist only behind a hover.
Hover is derived — one rule, no sixth token
The variant five-tuples stay Base / OnBase / Pressed / Subtle / OnSubtle — no Hover slot exists. Hover resolves by derivation:
Filled — hover meFilled variants: hover fill = midpoint of Base → Pressed. Text stays OnBase.
Quiet — hover meQuiet variants (Outline · Ghost): hover fill = SurfaceSubtle — the fill Pressed already uses.
Link — hover meLink: hover = underline, color unchanged; pressed keeps the Pressed token.
REQUEST: no Color.Lerp or precomputed VariantColors.Hover exists in the SDK. The derivation rule above is the contract; until the helper lands, web emits color-mix(in srgb, Base 50%, Pressed) and native desktop computes the same midpoint at paint.
Cursor & right-click
  • Cursor is vocabulary (BoxStyle.Cursor, shipped): web emits the CSS declaration; Photon registers a CursorRegion the host answers topmost-first (macOS → NSCursor).
  • Ladder: arrow (default) · pointer — links and web pressables · text — editable/selectable text · grab/grabbing — draggables (sheet grabber, thumbs) · col-resize/row-resize — grips · crosshair — fill handle.
  • Right-click never triggers a press and is never the only path. Where a component maps it (SwipeableRow actions, text menus), the same actions exist as visible controls.
Keyboard conventions
  • Tab reaches every interactive control; composite widgets are ONE tab stop with roving arrow focus — RadioGroup arrows exactly like SegmentedControl (move + select, wrapping); Tabs likewise.
  • Home/End go first/last in composites; min/max on sliders.
  • Activation: Space or Enter on buttons; Space alone on selection controls; Enter commits in fields.
  • Escape ladder: cancel the drag in progress → close the nearest dismissible surface → exit an edit trap.
  • Editing surfaces (Esc-to-exit, both targets): CodeEditor traps Tab for indentation — Esc releases the trap so the next Tab moves focus. Spreadsheet: Esc discards the cell draft; a second Esc leaves the grid.
  • Focus ring on focus-visible only (keyboard/switch), double ring per §01.

Overlay semantics — Dialog C2 · Drawer C5 · BottomSheet C1 · ActionSheet C3
  • role=dialog + aria-modal=true, named by the title (aria-labelledby); background inert while open.
  • Focus trap: Tab cycles inside; nothing behind is reachable.
  • Initial focus: Dialog → the safe (Ghost) action · BottomSheet → the sheet container · Drawer → the selected item.
  • Focus restoration: closing returns focus to the invoker — always, on every close path.
  • Esc closes when dismissible; the platform back gesture/button maps identically.
  • Overlay layers stay visible to the semantics tree — a dialog is seen (shipped: page AND overlay layers are collected).
The native mirror — what ships · what's a request
  • Ships: SemanticsTree.Collect(frame) — reading order from the realized layout, page + overlay layers; roles StaticText · Button · Link · TextField · CodeField · Adjustable · Image; name = inner text / label; identity = layout path; ActivatePath; increment/decrement on adjustables; scrolled-out content included; macOS bridge (iOS/Android bridges consume the same tree — roadmap).
  • REQUEST: Selected / Checked / Expanded state fields on SemanticNode — every table row above marked REQUEST waits on them.
  • REQUEST: custom actions for gesture components — SwipeableRow row actions, PullToRefresh refresh — so gestures mirror as actions, not just as visible fallbacks.
  • Until those land, native announces state ONLY where a shipped role carries it (Adjustable) — do not fake state through the name.
