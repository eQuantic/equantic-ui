Web-only affordances in this screen
Hover rows and buttons · dense 30–38px controls (pointer, not thumb) · sortable table headers · popover menus on more_horiz · pagination · keyboard shortcuts (⌘K) · multi-column breakpoints.
Everything else — color, type, spacing, radius, elevation, motion, variant & size vocabulary — is the same Layer 1 core the iOS and macOS samples resolve from. Nothing was re-derived for the browser: control geometry comes from Sizing.*(SizeVariant), animation from the named Motion roles, and the web realizer emits light-dark() so this page renders once for both themes.

Build target for Claude Code
An admin console on the eQuantic.UI web library: sidebar + topbar shell, KPI cards, a bar chart of rounded rects, a filterable data table with selection and pagination, and a settings form. Same token core as the mobile samples.
