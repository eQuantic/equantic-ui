Build target for Claude Code
One iOS app, six screens, no custom components — everything is a catalog component. Wire the tab bar, the sheet detents, the swipe actions and the pull-to-refresh, and the mobile SDK is exercised in a real flow, not a gallery.
Validation checklist
Safe areas on every edge component · 48dp hit rects (bar items, chevrons) · sheet gesture handoff with the inner scroll · 130% Dynamic Type without clipping · VoiceOver order per screen · light + dark parity (toggle above).
