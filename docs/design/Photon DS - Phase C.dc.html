Phase C — Surfaces & mobile patterns
All 16 specified (C1–C16) — C3 · C15 · C16 are specified ahead of the SDK (REQUEST). Overlays spend the scrim + optional blur budget; gesture releases run the sanctioned Release glide — 200ms smoothstep (§06) — toward a target picked by position + velocity; the velocity-taking spring stays a REQUEST.
C1

BottomSheet

new BottomSheet(detents: [Detent.Peek, Detent.Half, Detent.Full], initial: Detent.Half, dismissible: true, child: ...)
Transfer options
boltInstant (PIX)
scheduleSchedule
Full — top inset + 8
Half — 50% ← shown
Peek — content ≤ 40%
Specs & gestures
  • Surface fill · top corners Radius.Xl 20, bottom 0 (per-corner, §04) · E4 · grabber 36×4 BorderStrong Full, 8dp from top · content gutter S5 20 · bottom safe-area painted in sheet fill.
  • Detents: Peek (content height, ≤ 40%) · Half 50% · Full (top inset + 8). Drag follows 1:1; release snaps to nearest detent by position + velocity (Release glide — 200ms smoothstep (§06); velocity spring still REQUEST). Fling down > 700dp/s dismisses.
  • Scrim from Half up; tap dismisses when dismissible. Blur behind sheet = optional garnish, D4 budget (fence §00).
  • Gesture handoff: inner ScrollView scrolls only at Full; at scrollTop 0 a downward drag moves the sheet instead.
A11y · usage
  • Dialog role; focus trapped; first focus = title; Escape / Android back / scrim tap dismiss; grabber exposes "expand / collapse / close" custom actions. Reduce Motion: crossfade, no slide.
  • Use for contextual tasks that keep parent context: pickers (C14/C15), filters, detail peek. Non-modal Peek variant (no scrim) allowed for map-style companions.
  • Don't: full multi-step forms in a sheet; nested sheets; more than one open.
mouseDesktop & pointer — contract per §10
Pointer
The grabber drags with the mouse (cursor grab/grabbing); wheel scrolls inner content; scrim click dismisses when dismissible. The pointer/expanded tier presents a Dialog (C2) or anchored popover instead — the sheet is the touch presentation.
Keys
§10 overlay contract: focus trapped · Esc dismisses (unless dismissible: false) · Tab cycles inside · closing returns focus to the invoker.
Semantics
role=dialog + aria-modal=true; the grabber is hidden; detent changes announce ("half expanded", "full").
C2

Modal / Dialog

new Dialog(title, body, actions: [DialogAction ×≤2], dismissible: false)
Delete card?
"Work Visa ··· 4821" will be removed and its automatic payments will stop.
Keep card Delete
Rules
  • Width min(480, screen − 48), centered · Radius.Xl 20 · E5 · padding S5 20 · title Title 20/600 · body 15 TextSecondary, gap 8 · actions right-aligned Medium buttons, gap 8, top gap 20.
  • Confirm pattern: safe action = Ghost (first in focus order), committing action = Primary or Destructive. Max 2 actions — a third means you need an ActionSheet (C3 — not yet in SDK) or a screen.
  • Enter: scale 0.96→1 + fade, Base 200ms decelerate; scrim fades in parallel; exit ⅔ accelerate. Reduce Motion: fade only.
  • dismissible: false (default for destructive confirms): scrim tap and back are ignored — a button must resolve it.
  • A11y: alertdialog role — name = title, description = body; focus trapped, returns to invoker on close; Destructive announced "…, destructive".
  • Interrupting decisions only. Don't: multi-step flows, forms with > 1 field, stacked modals, information that a Banner or Toast covers.
mouseDesktop & pointer — contract per §10
Pointer
Scrim click dismisses only when dismissible; the dialog surface takes no hover — its buttons do.
Keys
§10 overlay contract verbatim: focus trap · initial focus = the safe (Ghost) action · Esc dismisses when dismissible, ignored when a button must resolve · close restores focus to the invoker.
Semantics
role=dialog + aria-modal=true, named by the title; background inert. Overlay layers stay visible to the semantics tree (§10).

C4

Toast / Snackbar

Toast.Show("Card removed", action: ("Undo", fn)?, duration: Duration.Default)
Card removed Undo
auto-dismisses after ~3s · enter = rise + fade, Slow decelerate
Rules
  • Inverse surface: TextPrimary as fill + TextInverse text (tokens §01) · Radius.Lg 14 · E3 · padding 12/16 · text 14/500, ≤ 2 lines · one action max, 14/700 in InverseAction (opposite-theme Primary — audited both modes).
  • Position: bottom-centered, 16dp gutters, max-width 560; floats above BottomNav / keyboard / home inset (moves with IME).
  • Timing: 4s default, 6s with action; enter rise+fade Slow 300ms decelerate, exit fade ⅔; swipe down/sideways dismisses (velocity-driven — Release glide — 200ms smoothstep (§06); velocity spring still REQUEST). Queue: one visible, FIFO.
  • A11y: polite live announcement; action exposed as custom action; timer pauses while a reader focuses the toast. Never make a toast the only path to an action — except Undo, which must also exist in history where feasible.
  • Toast = past-tense confirmation ("Card removed · Undo"). Persistent state = Banner (B18); decisions = Modal (C2).
mouseDesktop & pointer — contract per §10
Pointer
Hover pauses the auto-dismiss timer — the pointer twin of the reader-focus pause; the action underlines on hover (Link rule §10).
Keys
A toast never steals focus; Esc dismisses the visible toast. The action must also exist in-app (the Undo rule) — keyboard users are not raced by a timer.
Semantics
Polite live region (role=status); the action is exposed; the timer pauses during reader focus and pointer hover.

C6

SegmentedControl

new SegmentedControl(segments: ["1M","6M","1Y"], selected: 0, onChanged)
live — thumb slides Base 200ms standard
Rules
  • Track: SurfaceSubtle, Radius.Md 10, 4dp inset padding · heights 36 (Medium ★) / 44 (Large) · equal-width segments · label 13/600 — active TextPrimary, inactive TextSecondary.
  • Thumb: Surface + E1, radius = track − inset (7). Slides Base 200ms standard; press-down pre-tints the target label instantly; dragging the thumb scrubs across segments with a haptic per boundary.
  • 2–4 segments, short text only — labels must fit untruncated at ×1.3 Dynamic Type or the component asserts; icons-only segments allowed with labels for readers.
  • Whole control = one hit strip (≥ 48 with slop); exactly one segment always selected; switch takes effect immediately (view filter).
  • A11y: "1M, 1 of 3, selected" — arrows/swipe move selection; single focus stop.
  • Segmented filters the current view in place. Page-level content switching with swipeable pages = Tabs (B5); binary setting = Switch (B12).
mouseDesktop & pointer — contract per §10
Pointer
Hover on a non-selected segment = SurfaceSubtle wash (§10); cursor pointer; the thumb itself never hovers.
Keys
ONE tab stop, roving: ←/→ move AND select (wraps) · Home/End. RadioGroup (B13) arrows identically — same pattern, same wrap (§10).
Semantics
radiogroup / radio + aria-checked — segments switch a value, not panels (that’s Tabs). Native Selected field: REQUEST (§10).

Slider

new Slider(value, onChanged, min: 0, max: 100, step: null, haptics: true)
Continuous · value 60
R$ 400
Dragging — thumb grows 24→28, value bubble on inverse surface follows
Stepped · 5 detents (4dp dots), snaps on release + haptic
Rules
  • Track 4dp Radius.Full: active Primary, rest SurfaceSubtle (two rrects). Thumb 24dp white + E2 + 1dp Border (all themes — white thumb is the cross-platform constant).
  • Drag: no slop on the thumb (immediate capture); track-tap jumps with Base animation; thumb grows to 28 while held; bubble = inverse surface + Radius.Sm, Caption tnum, 10dp above.
  • Steps: 4dp dots — OnPrimary over active track, BorderStrong over rest; snap on release (Release glide — 200ms smoothstep (§06); velocity spring still REQUEST) + haptic per detent; min/max edges get a firmer haptic.
  • Hit: full-width 48dp strip; value label/min-max icons live outside the strip.
  • A11y: adjustable role — vertical swipe ±10% (or 1 step); announces "Limit, R$ 400"; live value announced with 200ms debounce while dragging.
  • Use for approximate continuous ranges (volume, limits). Precise numbers → Stepper (C8) or numeric TextInput; never as a page scrubber.
mouseDesktop & pointer — contract per §10
Pointer
Thumb hover grows it 24→26 and shows the value bubble (Motion.Press); cursor pointer; track click jumps (spec’d); thumb drag has no slop.
Keys
←/↓ −1 step · →/↑ +1 · PgUp/PgDn ±10% · Home/End min/max. Value announces debounced 200ms, as while dragging.
Semantics
role=slider + aria-valuenow/min/max (+ valuetext for units). Native Adjustable ships — increment/decrement already answer.

Stepper

new Stepper(value, onChanged, min: 1, max: 9)
remove 2 add
joined · 120×32, hit 48 per half
remove 1 add
at min — decrement disabled, never wraps
Rules
  • Joined form: 3 cells 40×32 in an Outline container (Radius.Md, hairline separators — three Boxes, not per-side borders); glyphs 18; value 15/600 tnum, min-width 40. Hit: 48dp per half, split at cell boundary.
  • Press: cell fills SurfaceSubtle instantly; value crossfades 100ms. Long-press auto-repeat: starts at 500ms, 8 steps/s, ×4 after 2s; haptic per tick.
  • At bounds the button disables (38%) — value never wraps around.
  • A11y: adjustable role — "Quantity, 2"; increment/decrement actions; each change announced.
  • Use for small bounded integers (quantity, guests, ≤ ~30 steps). Large or unbounded ranges → numeric TextInput; approximate ranges → Slider (C7).
mouseDesktop & pointer — contract per §10
Pointer
−/+ hover per the quiet rule (§10); press-and-hold repeats with the mouse exactly as with touch; cursor pointer.
Keys
The value group is one stop: ↑/→ increment, ↓/← decrement, Home/End clamp; the −/+ buttons are also plain stops.
Semantics
Group named by its label; buttons announce "decrease/increase"; value changes announce. Native: Adjustable increment/decrement.
C9

PullToRefresh

new PullToRefresh(onRefresh: async fn, child: List | ScrollView)
Rules
  • Top-overscroll gesture on root lists. Pull maps with 0.5 asymptotic resistance; commit threshold 72dp.
  • Indicator: Spinner Md 24 (Primary) in a 40dp Surface circle + E2. While pulling, spinner bars fill clockwise with pull fraction (deterministic — the user can feel the threshold); past threshold it starts spinning.
  • Release ≥ 72dp: settles at 72dp (Release glide — 200ms smoothstep (§06); velocity spring still REQUEST), onRefresh runs, min visible 500ms, collapses Slow decelerate. Below threshold: springs back, nothing fires.
  • Platform flag: iOS translates content with the pull; Android floats the circle over static content.
  • A11y: refresh exposed as a custom action on the scroll region (readers can't pull); announces "refreshing" → "refreshed"; Reduce Motion: static indicator, fade transitions.
  • Root content lists only — never inside carousels or sheets; don't co-opt the gesture for anything but refresh.
mouseDesktop & pointer — contract per §10
Pointer
No pull on wheel/trackpad — overscroll is not a pointer gesture. Desktop surfaces an explicit refresh control (toolbar IconButton or menu item) + ⌘R/F5.
Keys
The refresh action must be reachable as a real control — the gesture is never the only path (§10).
Semantics
Refresh exposed as a custom action on the scroll region (spec’d): native custom actions REQUEST (§10); announces "refreshing" → "refreshed".

SwipeableRow

new SwipeableRow(child: ListItem, trailing: [RowAction ×≤2], leading: [RowAction ×≤2]?)

Rules
  • Horizontal slop 12dp wins over vertical scroll; row translates 1:1; actions revealed behind: 72dp panes, status Base fill + OnBase icon Dense + Caption 10.5/700.
  • ≤ 2 actions per side; destructive always at the outer edge. Release snaps to n×72 or closed (Release glide — 200ms smoothstep (§06); velocity spring still REQUEST, by position + velocity). Full swipe > 60% width commits the outer action — pane stretches to full width first (Fast).

mouseDesktop & pointer — contract per §10
Pointer
Mouse drags don’t swipe — on pointer the row’s actions surface via right-click context menu (the C3 presentation) plus the row’s own visible affordances.
Keys
Focused row: menu key / Shift+F10 opens the actions; destructive commit stays two-step. The same actions live in the row’s detail (spec’d rule).
Semantics
Every swipe action mirrors as a custom accessibility action (normative) — REQUEST on native until SemanticNode carries custom actions (§10).

Rules
  • Dot 8dp Radius.Full BorderStrong; active = 20×8 Primary pill; gap S2 8. Active pill grows / previous shrinks Base standard, interpolating with carousel drag fraction (worm effect — two rrects, engine-honest).

Tooltip

provided by IconButton(label:) — Tooltip.For(control, text) for custom anchors
Scan invoice qr_code_scanner long-press 500ms — bubble 8dp above, no caret (fence: no paths)
Rules
  • Inverse surface (TextPrimary fill + TextInverse text) · Caption 12/500 · padding 6/10 · Radius.Sm 6 · E3 · max-width 200, ≤ 2 lines. No caret arrow in v1 — proximity + shadow anchor it (flips below near the top edge).

Semantics
role=tooltip joined to the trigger via aria-describedby — a description, never the name.
