A1

Box

new Box(style: BoxStyle, child: VisualNode?)

The atom. A Box is the engine's rrect surfaced as a component: 1 fill draw + optional border draw + optional shadow draw. Every visible surface in the system decomposes into Boxes.

Anatomy
③ shadow bounds
② border · uniform
① child + padding
Paint order: shadow → fill (solid or 2-stop linear gradient) → border (inside stroke) → child (clipped to rrect if Clip).
BoxStyle field
Spec
Width · Height
dp · Hug (default) · Fill. Resolution: explicit > Fill > Hug. Min/Max caps supported.
Padding
EdgeInsets of Space tokens. No margin exists — outer space belongs to the parent's Gap/Padding.
Background
ColorToken, or LinearGradient(from, to, angle) — exactly 2 stops (fence).
CornerRadius
Per-corner: Corners(tl, tr, br, bl) or a Radius token for all four. Overflowing radii normalize CSS-style.
Border
Border(color, width) — uniform width only; drawn inside. Per-side widths are outside the fence: compose thin Boxes instead.
Shadow
Elevation(0–5) token only — free-form ShadowSpec requires design review.
Clip · Opacity
Clip = own rrect. Opacity < 1 forces a saveLayer — budgeted, use for disabled (0.38) and transitions, not decoration.
Transform
2D translate · scale · rotate about a pivot. Does not affect layout (paint-only).
A11y
None by default (invisible to readers). Attach Semantics(label, role) to promote; interactive Boxes are a spec smell — use Button.
mouseDesktop & pointer — contract per §10
Pointer
Inert — arrow cursor, no hover, right-click falls through. A Box gains pointer states only by composing Pressable.
A2

Row · Column

new Row(gap: Space.S2, main: MainAlign.Start, cross: CrossAlign.Center, children: [...])

The only flow layout. Own C# flex implementation — single main axis, Gap tokens between children, Flex(n) children share leftover space by weight.

Gap + Flex — live geometry
hug
Flex(1)
Flex(2)
↑ gap = Space.S2 (8dp), uniform, never collapses
Truncation contract: text children shrink to ellipsis before any sibling is pushed out; fixed children (icons, avatars) never shrink. This rule is what makes ListItem, AppBar and Chip safe at 130% Dynamic Type.
Prop
Spec
main
Start · Center · End · SpaceBetween. (Around/Evenly cut from v1 — use Spacers.)
cross
Start · Center (Row default) · End · Stretch (Column default for full-width children).
gap
Space token. The only legal spacing between siblings.
wrap
Row only: children flow to new lines (chip groups). Line spacing = gap.
RTL
Row mirrors automatically in RTL locales; reading/focus order stays = child order.
A11y
Transparent container; announces nothing. Focus traversal = child order, depth-first.
mouseDesktop & pointer — contract per §10
Pointer
Inert layout — no hover, arrow cursor. Pointer behavior belongs to the children.
A3

Stack

new Stack(align: Alignment.TopStart, children: [base, Positioned(top: 8, end: 8, child: badge)])

Z-axis composition. Paint order = child order (last on top); hit-testing walks top-down. Sizes to its largest non-positioned child.

notifications
3
badge = Positioned(top:−5, end:−5)
negative insets allowed;
parent must not Clip
  • Positioned(top/end/bottom/start, width?, height?) — inset-anchored children; two opposite insets stretch the child.
  • Non-positioned children obey align (9 anchor points).
  • Canonical uses: badge-over-icon, media overlays (gradient scrim + caption), FAB over scroll content, skeleton shimmer layers.
  • Not a free-form canvas: absolute screens built from Positioned everywhere fail review — compose Rows/Columns.
  • A11y: order = child order (base first, overlays after). Decorative overlay layers marked hidden.
mouseDesktop & pointer — contract per §10
Pointer
Inert — z-order does not change hit order: the topmost hit-testable child wins, exactly as on touch.

Spacer

new Spacer() · new Spacer(flex: 2) · Spacer.Fixed(Space.S6)
Back
Spacer() — invisible, flex 1
Next
  • Draws nothing, hits nothing, announces nothing — layout-only.
  • Flexible form collapses to 0 when siblings need the space (it loses to content).
  • Spacer.Fixed is rigid — prefer parent gap; use Fixed only for one-off rhythm breaks.
  • Anti-pattern: chains of Fixed Spacers to fake padding — use Padding.
mouseDesktop & pointer — contract per §10
Pointer
Never hit-testable — clicks pass through to whatever sits beneath.
A5

SafeArea

new SafeArea(edges: Edges.All, minimum: EdgeInsets.Zero, child: ...)
Behavior
  • Pads its child by the platform insets (notch, home indicator, status bar, display cutouts) on the selected edges.
  • minimum merges via max(inset, minimum) — gutters never collapse to zero on rectangular screens.
  • Consumption: a SafeArea zeroes the inset for its subtree — nested SafeAreas never double-pad.
  • Insets update per-frame from the shell: rotation, in-call status bar, foldable posture.
Usage
  • Wrap screen content, not edge components — AppBar, BottomNavigation and BottomSheet handle their own insets (they paint under the inset and pad inside; §08).
  • Don't wrap ScrollView in a bottom SafeArea — pass the inset as content padding instead so content scrolls under the home indicator but rests clear of it.
  • A11y: transparent.
mouseDesktop & pointer — contract per §10
Pointer
Desktop windows have no notches or home indicators — every inset resolves to 0 and the node is a pass-through. Never reserve fake inset space on pointer targets.
A6

ScrollView

new ScrollView(axis: Axis.Vertical, child: ...) — bounded content only; virtualized lists are List (B2)
Aspect
Spec
Physics
Platform-native curves. iOS: exponential decay (normal rate 0.998) + rubber-band overscroll. Android: fling friction + stretch overscroll (scale transform — inside the fence; no glow arc).
Gesture
Drag slop 8dp before capture; captures from pressed children (press cancels into scroll). Release injects gesture velocity into fling. Tap during deceleration stops dead, second tap interacts.
Scrollbar
3dp pill, Radius.Full, BorderStrong @ 60%, 2dp from edge. Appears on scroll, fades out 800ms after idle (Fast/Base motion). Non-interactive in v1.
Insets
contentPadding merges safe-area bottom (§A5). Keyboard: bottom inset grows by IME height; focused input kept visible (M4).
Nesting
Cross-axis nesting fine (horizontal carousel in vertical page). Same-axis nesting asserts in debug — restructure with List sections.
Engine path
Scroll = translated rrect clip. The compositor caches the content layer; a scroll frame re-encodes zero components — it updates one transform. 120Hz fling is a translate-only frame well inside the 8.33ms budget.
A11y
Exposed as a scrollable region; VoiceOver 3-finger / TalkBack 2-finger swipes page by 80% viewport and announce "Page X of Y" when paging is enabled. Offscreen children stay in the semantics tree (readers scroll them in).
mouseDesktop & pointer — contract per §10
Pointer
Wheel / trackpad scrolls with platform inertia; the scrollbar is overlay-style, appears on scroll or container hover, and is draggable. Scrolling itself hovers nothing.
Keys
Focused region: ↑/↓ line · PgUp/PgDn viewport · Home/End extremes. Space stays with the focused control, not the scroll.
Semantics
Scrolled-out content stays in the semantics and focus walks (§10) — clipping guards the pointer, not the reader.
A7

Divider

new Divider(inset: DividerInset.Leading) · new Divider(axis: Axis.Vertical)
Full-bleed — section boundaries
Inset leading 16 — inside lists, aligns with content after leading icon
Middle 16 — grouped card interiors
Vertical — toolbar separators, stat groups
  • 1dp logical thickness, Border token; engine snaps to the physical pixel grid so hairlines never double-render.
  • Consumes exactly its thickness — vertical rhythm comes from the parent's gap, never from Divider "spacing" props (it has none).
  • List/Card provide dividers via their own props (B1/B2) — hand-placed Dividers between ListItems fail review.
  • Don't fake card edges with Dividers — that's Border.
  • A11y: invisible to screen readers.
mouseDesktop & pointer — contract per §10
Pointer
Inert, decorative.
Semantics
Hidden from the semantics tree — a divider is paint, not content.
A8

Text

new Text("…", role: TypeRole.BodyL, color: theme.TextPrimary, maxLines: 2, overflow: Overflow.Ellipsis)

A shaped paragraph on the glyph atlas. Role-driven — free-form font sizes don't exist in the component API; a TypeRole resolves size, weight, line-height, tracking and the Dynamic Type cap (§02).

Truncation — live (resize-safe)
maxLines: 1 · Ellipsis
Transfer received from Ana Beatriz Nogueira — invoice #08122, quarterly settlement
maxLines: 2 · Ellipsis
Wrapping happens at shaping time; the ellipsis glyph replaces the last cluster that fits, so bidi and emoji boundaries are respected instead of cutting mid-cluster.
Aspect
Spec
Layout
Width: fills available line box, hugs when unconstrained. Height: line count × line-height. Baseline exposed to parents for cross-align.
Dynamic Type
Scales by OS factor to the role cap; re-shape + re-layout, atlas re-uses whitelist sizes. Never scales below ×1.
Rich runs
Span(text, weight?, color?) children for inline emphasis. One role per paragraph — mixed roles are separate Texts.
Selection
Not selectable in v1 (caret/selection metrics land with TextInput, M4).
A11y
Role: static text; label = full untruncated string (readers speak past the ellipsis). Merges into parent semantics when inside labeled controls.
mouseDesktop & pointer — contract per §10
Pointer
I-beam over selectable text; drag selects; right-click = the platform text menu (Copy). Non-selectable text keeps the arrow cursor.
Semantics
StaticText — the run’s text is its accessible value.
A9

Heading · Label

new Heading("Portfolio", level: 1) · new Label("Email", target: emailInput)
Heading — semantic Text
  • Level 1 → Heading role, 2 → Title, 3 → Label-strong. Visual role can be overridden; semantics can't.
  • Announced as "heading, level N" — VoiceOver rotor / TalkBack heading navigation jump between them.
  • Exactly one level-1 per screen (debug assert). Never pick Heading for its looks — that's Text(role:).
Label — control caption
  • Label role type (13/16/600), TextSecondary by default; 6dp gap above its control.
  • target: binds it as the control's accessible name — the reader speaks "Email, edit text" focusing the input, and the label itself is skipped.
  • Tapping a Label forwards the press to its target (extends the hit area upward).
mouseDesktop & pointer — contract per §10
Pointer
As Text (A8) — I-beam when selectable.
Semantics
Web emits real heading levels; native marks the node as a header so readers can jump by heading.
A10

Icon

new Icon(Icons.Search, size: IconSize.Dense, color: theme.TextSecondary, label: "Search")
Optical box
search
box 24
glyph ≈ 20 live area
Glyphs are drawn in a square em-box; the built-in ~2dp bleed keeps optical weight even. Alignment nudges beyond ±1dp indicate a broken glyph, not a layout fix.
Aspect
Spec
Sizes
Sm 16 · Dense 20 · Md 24 · Lg 32 — the atlas whitelist. Arbitrary dp sizes are a compile-time error.
Color
Single tint from a ColorToken — alpha-mask glyphs tint like text. Two-color art is an Image, emoji ride the color atlas.
Fill state
Outline ↔ filled = distinct glyphs (Icons.Heart / Icons.HeartFilled). State change may crossfade 100ms; no path morphing exists.
Scaling
Ignores Dynamic Type (§07). Pre-rasterized @1x/2x/3x per size — never bitmap-stretched at runtime.
A11y
No label → decorative, hidden from readers. With label → image role. Inside labeled controls the icon is always hidden (the control speaks).
mouseDesktop & pointer — contract per §10
Pointer
Inert — an icon never takes hover on its own; the owning control does.
Semantics
Labelled Icon announces its label (image role); unlabelled is decoration and is hidden.

Image

new Image(source, fit: ImageFit.Cover, radius: Radius.Md, alt: "…")
Fit modes — 96×64 slot, 1:1 source
Contain
Cover · center crop
Stretch (distorts)
corners fixed
center stretches
NineSlice(insets: 14)
9-slice serves stretchable art (speech bubbles, decorated panels) without vector paths — corners stay crisp at any size.
Aspect
Spec
States
Loading: SurfaceSubtle fill (or Skeleton shimmer when inside one). Error: SurfaceSubtle + Md broken-image glyph in TextMuted. Decoded image crossfades in, 200ms.
Radius
Radius token clips via rrect (per-corner ok). Border allowed over the clip (avatar ring).
Memory
Decoded at target size (never full-res into a thumbnail); atlas pages evict LRU under memory pressure (M4 lifecycle).
Layout
Needs bounded size from parent or explicit dims; intrinsic aspect ratio used when one axis is known.
A11y
alt: required or explicit decorative: true — omitting both is a debug warning. Alt read as image role.
mouseDesktop & pointer — contract per §10
Pointer
Arrow cursor; right-click = platform default (web: the browser image menu). No hover states.
Semantics
Labelled = image role + label; unlabelled = decorative, hidden.

Behavior
  • Press: fill swaps to Pressed on touch-down (same frame, ≤ 50ms); release fades back Fast 100ms. Activation fires on release-inside.
  • Cancel: drag beyond 12dp of the hit rect, or scroll capture, reverts without firing.
  • Loading (normative — matches the shipped SDK): the leading slot swaps to the spinner, the label STAYS — width is stable because the label never changes, no freeze needed. Presses swallowed, announced "busy". Never shrink or re-flow neighbors.
  • Layout: hugs label by default; expand: true fills the row (checkout CTAs). Single line, ellipsis — never two lines.
Accessibility
  • Role button; name = label text (icon is hidden). Icon-only composition is IconButton (A13), which requires a label.
  • Announces: "Continue, button" · disabled: "…dimmed" · loading: "…busy".
  • Focusable via keyboard/switch; ring per §01; activation on Space/Enter/double-tap.
DO
  • One Primary per screen region — it marks the action.
  • Pair Primary + Ghost/Outline for confirm/dismiss.
  • Use XLarge full-width for thumb-zone checkout CTAs.
  • Verb-first labels: "Save changes", not "OK".
DON'T
  • Two Primaries side by side; Destructive as the default focused action.
  • Small buttons for primary flows — Small is for dense toolbars and cards.
  • Link variant inside button rows (it's for inline text contexts).
  • Status variants (Success/Warning/Info) as decoration — they assert an outcome.
mouseDesktop & pointer — contract per §10
Pointer
Hover (pointer-only): filled variants = Base→Pressed midpoint fill · Outline/Ghost = SurfaceSubtle fill · Link = underline (§10 rule). In/out animates Motion.Press 100ms; hover never fires on touch and clears when the pointer leaves the window. Cursor: pointer on web, arrow on native desktop. Right-click never presses.
Keys
Tab focuses (double ring §01) · Space or Enter activates on key-up · disabled stays in the walk, announced dimmed, activation refused · loading swallows activation.
Semantics
Web role=button, name = label; loading = aria-busy=true — a state, not a name change. Native: Button role, "…busy" while loading.

Behavior & a11y
  • Press/cancel physics identical to Button.
  • Toggle form: role toggle button, announces "selected"; glyph crossfades outline↔filled 100ms.
