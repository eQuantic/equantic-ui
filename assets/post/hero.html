One component class.
A web page and a native screen.

HomePage.cs
[Page("/")]
public sealed class HomePage : StatefulComponent
{
    private int _count;

    public override VisualNode Build(ComponentContext context) =>
        Column(gap: Space.S4, children: [
            Text($"Count: {_count}", TypeRole.Display),
            Button("Increment", onPressed: () =>
                SetState(() => _count++)),
        ]);
}
WEB

A server-rendered page

  • Hydrates, then routes on the client
  • Split per route, atomic CSS generated for you
  • A ~110 KB runtime, not a megabyte one. No WASM boot.
NATIVE

macOS · iOS · Android

  • Drawn on the GPU by our own engine: Metal, Vulkan
  • Camera, location, biometrics and secure storage injected
  • No WebView. No Skia.
C# in. No JavaScript, no CSS, no Node toolchain.
