# One top-level type per file. These are the exceptions: the path, how many types were MEASURED
# there, and why the file is the unit. The list may ONLY SHRINK, and an entry is not a licence for
# the NEXT type either — the count is checked, so a listed file cannot quietly grow one.
#
# The reasons, and what each claims:
#   interop header      one native header transcribed in one place; splitting it loses the mirror
#   closed hierarchy    the cases ARE the type, and a case alone means nothing
#   protocol set        one wire protocol's records, which version together
#   vendor schema       one library's options object transcribed, same argument as an interop header
#   not looked at yet   MEASURED, not judged — nobody has decided whether this file is the unit
#
# Most entries say "not looked at yet", and that is the honest state: judging them is its own body
# of work, and a plausible sentence nobody checked would make the list unshrinkable instead. No
# count is quoted in this header, because regeneration keeps the header verbatim and would leave a
# quoted one behind as the list shrank — `grep -vc '^#'` answers it from the file itself.
#
# Regenerate with EQ_UPDATE_ONE_TYPE_BASELINE=1 after a REMOVAL. It carries every reason across and
# writes "not looked at yet" for a file that is newly over the line, which is not an approval: it
# is a file nobody has judged, and the diff is where that gets noticed.
