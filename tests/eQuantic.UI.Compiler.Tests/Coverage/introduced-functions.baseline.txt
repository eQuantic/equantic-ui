# quietly write one more.
#
# The reasons, and what each claims:
#   arguments only      the function reads its parameters, and every C# part is passed in
#   no C# inside        a callback of the runtime's or the platform's own, holding no translated C#
#   the IR's writer     where the IR's arrow nodes and a template's bound parts are written
#   no statement there  the function holds C# only where no statement or body can declare a
#                       temporary instead (an initializer, a constructor's base call), which C#
#                       never lets await, and it runs once each time the C# does
#   a type, not a function   a TypeScript function TYPE, written into an annotation: nothing runs
#   not looked at yet   MEASURED, not judged: nobody has decided whether the function holds C#
#
